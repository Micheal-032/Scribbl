# Scribbl
Smart Notes Desk

*Overview:
Smart Notes Desk is a simple yet intelligent note-making web application designed for laptop users.
It enables users to capture ideas, organize them efficiently with smart tagging, and visualize their progress over time through an integrated tracking system.

*Planned Features:

Smart tagging and note organization
Modular note blocks (text, checklist, and code snippets)
Theme customization (light and dark modes)
Progress tracking with version history
Visual representation of note growth over time
Optional Python backend for AI-based summaries

*Tech Stack:

Frontend: HTML, CSS, JavaScript
Visualization: Chart.js
Optional Backend: Python (Flask)
Current Progress
Base user interface and core note management system implemented
Progress tracking and version visualization integrated
Upcoming enhancements include improved UI design and intelligent tagging
